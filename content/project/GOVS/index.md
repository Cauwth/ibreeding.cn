GOVS (<span style="color:red">G</span>enome <span style="color:red">O</span>ptimization via <span style="color:red">V</span>irtual <span style="color:red">S</span>imulation) is an integrative R package for maize breeding that streamlines genome optimization via virtual simulation achieve guidance of lines selection and population development. GOVS describes a promising strategy that can help breeders to select materials in a purposeful and directional manner, with the purpose of enabling breeders to combine others technologies with rapidly genetic gain benefit by genome optimization.Above figure illustrate the framework of GOVS, GOVS consists of four main modules:

- [Genome optimization module](https://govs-pack.github.io/Tutorial/#genome-optimization-module) for virtual simulation of optimal genome.
- [Extraction & assembly module](https://govs-pack.github.io/Tutorial/#extraction-and-assembly-module) for extraction and assembly of virtual genome.
- [Statistic module](https://govs-pack.github.io/Tutorial/#statistic-module) for contribution statistic of virtual genome.
- [Genome prediction module](https://govs-pack.github.io/Tutorial/#genome-selection-prediciton-module) for genotype-to-phenotype prediction of optimal genome.

GOVS was developed by [Qian Cheng](/authors/qian-cheng/) in 2021.

Please read the [tutorial](https://govs-pack.github.io/) for details!
